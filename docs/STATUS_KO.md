# 현재 연구 상태 — v0.5.1 기반 + observation-gate 연구 증분

업데이트: 2026-10-13. 기존 정식 릴리스는 v0.5.1이며 새 정식 tag를 발행하지 않았습니다. [기존 상태 원문](STATUS_v0_5_1_KO.md)은 보존합니다.

## 최종 목적

실제 원단의 색·직조·광택·비침을 새로운 조명·시점·역광에서도 충실하게 재현하는 것이 목적입니다. 상세 시뮬레이터는 이를 위한 기반이며, 실제 제품 복원·강한 RGB 대비 추가 관측·메타표면의 시스템 이득은 서로 다른 검증 단계입니다. 염색·퇴색은 계속 보류합니다.

## 버전별 근거를 혼합하지 않는다

기존 v0.5.1의 전체 425 tests, v0.5의 216회 단면/반지름 렌더, 32회 물리 기준, 72회 수치 척도 렌더 기록은 이전 실행의 근거입니다. 이번 새 테스트 55개를 단순 합산한 480개 전체 통과를 주장하지 않습니다. 새 3D/Mitsuba 렌더는 0회이고 실제 원단 측정도 0개입니다.

## 현재 병목과 다음 순서

기존에 관측한 단면 32->64의 큰 radiance 변화는 아직 열린 문제입니다. 이번의 독립 첫 반사 기준은 facet 법선과 detector 정렬을 분리할 도구를 추가한 것이며, 기존 결과의 원인 전부를 확정하지 않습니다.

1. 원형 analytic reference -> 곡선 섬유 -> 두 섬유 교차 -> 작은 patch 순으로 관측 오차 구간을 제한합니다. 0을 포함하는 CI 대신 사전에 선언한 동등성 허용량을 사용합니다.
2. 새 국소 부피 profile을 기존 material labels와 연결하고, 굽은 mesh 부피·self-contact·광학 수렴을 검증합니다.
3. 수렴한 explicit fiber를 기준으로 ply/yarn 표현의 실제 반사·투과·영상 오차를 평가합니다. 투영 통계 fitting만으로 BSDF 정확도를 주장하지 않습니다.
4. 실제 thread/원단 R/T를 교정하고 좋은 다중조명 RGB와 같은 예산에서 추가 관측을 비교합니다. 유용한 채널에 대해서만 기존 광학과 메타광학의 전체 시스템을 비교합니다.

현재 실크·코튼·큐프라·린넨의 물성이 실측 교정됐다거나, 새로운 카메라의 재질감 전달 능력이 입증됐다는 결과는 없습니다.
